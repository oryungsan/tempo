# Tempo

**Windows용 타이머 · 알람 · 리마인더 · 스톱워치 · 카운트다운 · 디데이 · 월드타임** — 설치 없이 실행 파일 하나로 동작하고, 여러 PC 를 연동할 수 있습니다.

여러 단계로 이어지는 루틴 타이머, 화면에 떠 있는 카드, 모래시계·원형·디지털 같은 여러 디자인, 포모도로, Microsoft To Do 연동 리마인더를 지원합니다.

## 내려받기

[**Releases**](../../releases/latest) 에서 `Tempo-x.y.z-windows-x64.zip` 을 받아 압축을 풀고 `tempo.exe` 를 실행하세요.

- Windows 10 (1903 이상) · Windows 11, 64비트
- 처음 실행할 때 「Windows의 PC 보호」 창이 뜨면 **추가 정보 → 실행** 을 누르세요. (코드 서명 인증서가 없는 개인 프로그램이라 뜨는 안내입니다)
- 원하는 폴더(예: `C:\Tools\Tempo`)에 두고 실행한 뒤, **설정 → 바로가기 만들기** 로 시작 메뉴·바탕 화면에 추가하거나 **Windows 시작 시 자동 실행** 을 켜면 됩니다.

## 기능

### 타이머
- **단계 루틴**: 단계 여러 개를 차례로 진행 (예: 스트레칭 30초 → 휴식 10초 → …). 단계마다 다른 끝 소리
- **포모도로**: 집중 · 짧은 휴식 · 긴 휴식 · 간격만 정하면 자동 구성, 회차 표시
- 여러 타이머 동시 실행, 끝나면 반복, **끝나기 N초 전 예고음**, 단계마다 멈추고 기다리기
- **전역 단축키**: 타이머마다 시작·일시정지 / 처음으로 (다른 프로그램을 쓰는 중에도)
- **떠 있는 카드**: 항상 위에 뜨는 작은 카드 — 끌어서 이동, 가장자리를 끌어 크기 조절, 누르면 단계 목록, 오른쪽 클릭 메뉴
- **집중 화면**: 카드를 누르면 큰 화면 (포모도로는 집중/짧은 휴식/긴 휴식 탭, 오늘의 기록)

### 디자인 6종 × 색 테마 10종
클래식 · 원형 · **모래시계**(모래가 떨어지고 단계마다 뒤집힘) · 미니멀 · 디지털(7세그먼트) · 채우기
— 다크 · 미드나잇 · 포레스트 · 선셋 · 오션 · 노르딕 · 모노 · 라이트 · 로즈 · 샌드. 타이머마다 다른 디자인도 가능

### 알람 · 리마인더 · 스톱워치
- **알람**: 시각 + 요일 반복(매일·평일·주말·한 번), 다시 알림
- **리마인더**: 할 일 + 시각 + 메모 + 반복(매일·평일·매주·매월). 울리면 완료 / 10분 뒤 / 1시간 뒤
  - **Microsoft To Do 연동**: 설정 → Microsoft To Do → 「Microsoft 계정 연결」 → 표시되는 코드를 로그인 페이지에 입력. 목록 하나와 양방향 동기화 (휴대폰 To Do 앱과 함께 보기)
- **스톱워치**: 구간 기록

### 카운트다운 · 디데이 · 월드타임
- **카운트다운**: 정한 날짜·시각까지 남은 시간을 초 단위로 (`44일 13:30:53`). 그때가 되면 알림 창 + 소리, 만든 때부터 진행 막대
  - 빠른 설정: +10분 · +1시간 · +1일 · 오늘 18:00 · 내일 09:00 · 새해
- **디데이**: 세는 방식 3가지
  - **남은 날** — 시험 · 여행 · 마감: `D-23` → 당일 `D-Day` → 지나면 `D+5`
  - **그날부터** — 기념일 · 금연: 첫날을 1일째로 (`100일째`), 다음 100일 · 1주년까지 남은 날
  - **매년** — 생일 · 결혼기념일: 다음 그날까지 `D-108`, 몇 번째인지 (2월 29일은 평년엔 2월 28일)
  - **알림 세부 설정**: 알림을 여러 개 — 하나씩 「며칠 전(당일~365일) · 시각 · 켬/끔」 (예: D-7 20:00 · D-1 21:30 · 당일 08:00)
    - 매년은 해마다, 그날부터는 **100일마다 / 1000일마다 / 안 함** + **주년** 켬/끔
    - 소리 · **끌 때까지 / 한 번만**, 알림 창에서 **10분 뒤 · 1시간 뒤** 다시 알림
    - 편집 창과 카드에 **다음 알림** 시각 표시
  - 하루 안으로 다가오면 그날 0시까지 **초 단위** (`D-Day까지 12:27:35`)
- **사이드바 고정**: 카운트다운·디데이를 메인 창 왼쪽 아래에 늘 표시
- **떠 있는 카드**: 카운트다운·디데이도 타이머처럼 바탕 화면 카드로 — 끌어서 이동(위치 기억), 두 번 누르면 편집, 오른쪽 클릭 메뉴
- **월드타임**: 도시별 아날로그 시계(낮 = 밝은 판, 밤 = 어두운 판) · 시각 · 시차 · 오늘/내일/어제 · UTC 차이. 서머타임 자동
  - 60여 개 도시는 한글로, 그 밖의 시간대는 영문 이름으로 검색 (예: `Reykjavik`)
  - **시간 미리 보기**: 막대를 밀면 모든 도시의 그 시각을 한눈에 (회의 시간 맞추기)

### 소리
내장 합성음 15종 + 내 소리 파일(wav · mp3 · flac · ogg), 미리 듣기, 전체 볼륨

## PC 연동

Tempo 가 깔린 여러 PC 에서 **같은 타이머 · 알람 · 리마인더 · 카운트다운 · 디데이 · 월드타임**을 쓰고, 한 PC 에서 시작 · 일시정지 · 단계 이동하면 다른 PC 도 그대로 따라갑니다 (같은 내부망 또는 Tailscale).

1. 한 PC: **설정 → PC 연동 → 호스트** — 연동 코드(8자리)와 이 PC 주소가 보입니다
2. 다른 PC: **설정 → PC 연동 → 참여** — 호스트 주소와 연동 코드를 넣으면 연결
3. 처음 연결하면 두 PC 를 **합칩니다** — 이름이 같은 타이머 등은 호스트 것 하나로, 나머지는 양쪽에 추가 (참여 PC 의 원래 데이터는 `data.before-sync-….json` 으로 보관)

- PC 마다 따로: 테마 · 볼륨 · 카드 표시 · 카드 위치 · 사이드바 고정 · 단축키 동작 PC
- 다른 PC 에서 시작한 타이머의 소리 · 완료 창은 PC 마다 켜고 끔 (기본 끔 — 화면 · 카드만 같이 움직임)
- 알림 창을 한 PC 에서 닫으면 다른 PC 에서도 닫힘
- 호스트 PC 는 TCP 47840 을 받아야 합니다 (Windows 방화벽에서 Tempo 허용)
- 두 PC 가 끊겨 있는 동안 바꾼 것도 다시 연결되면 더 최근 것으로 맞춥니다

## 자동 업데이트

켤 때와 6시간마다 이 저장소의 최신 릴리스를 확인합니다 (설정 → 업데이트: **자동** / 알림만 / 끔).

- 새 버전이 있으면 `tempo.exe` 를 내려받아 릴리스 설명의 **SHA-256** 과 맞는지 검사합니다
- **타이머가 모두 쉬고 울리는 알림이 없을 때만** 바꿉니다 (편집 창이 열려 있거나 스톱워치가 돌면 기다림)
- 바꾼 뒤 1~2초 만에 다시 켜지고, 이전 버전은 `tempo.old.exe` 로 남습니다
- 새 버전이 45초 안에 정상 응답하지 않으면 **이전 버전으로 자동으로 되돌리고**, 그 버전은 다시 받지 않습니다
- 실행 파일이 있는 폴더에 쓸 권한이 있어야 합니다 (`C:\Program Files` 처럼 관리자 전용 폴더에 두면 「알림만」처럼 동작)

## 데이터 · 제거

- 설정과 데이터: `%APPDATA%\Tempo\` (`data.json`, 기록 `tempo.log`)
- Microsoft 로그인 정보는 Windows DPAPI 로 암호화되어 이 PC · 이 Windows 계정에서만 쓰입니다
- **제거**: 설정에서 「Windows 시작 시 자동 실행」을 끄고 → 트레이 아이콘 → 종료 → `tempo.exe` 와 `%APPDATA%\Tempo` 폴더를 지우면 끝

## 자동화 (로컬 API)

`http://127.0.0.1:47830` (이 PC 안에서만 접근)

| 주소 | 설명 |
|---|---|
| `/api/timers` | 모든 타이머 상태 |
| `/api/timer?name=라면 3분&do=start` | 이름(또는 `id=`)으로 조작 — `start` `toggle` `pause` `resume` `reset` `skip` |
| `/status` · `/start` … | 설정의 「연동 타이머」 하나를 짧은 주소로 |
| `/api/show` | 메인 창 열기 |
| `/api/countdowns` · `/api/ddays` · `/api/world` | 카운트다운 남은 시간 · 디데이 · 월드타임 시각 |
| `/api/update` (`?do=check` · `?do=apply`) | 자동 업데이트 상태 · 지금 확인 · 지금 업데이트 |
| `/api/sync` (`?mode=host\|join\|off&code=…&host=…`) | PC 연동 상태 · 설정 |

## 직접 빌드

Rust (stable, `x86_64-pc-windows-gnu` 또는 `-msvc`).

```
cargo build --release
```

- GNU 툴체인은 `dlltool` 이 PATH 에 있어야 합니다 (`build.sh` 참고).
- **릴리스**: `Tempo-x.y.z-windows-x64.zip` 과 함께 **`tempo.exe` 를 따로 첨부**하고, 설명에 `` SHA-256 (exe): `<64자리>` `` 줄을 넣어야 자동 업데이트가 받습니다
- 실행 파일 아이콘 · 버전 정보는 `assets/tempo-res.o` 를 링크합니다. 바꿀 때만 `python tools/make_res.py <버전> <windres 경로>` 로 다시 만드세요.

egui · eframe · rodio · tiny_http · tray-icon · rfd · ureq 를 사용합니다.
