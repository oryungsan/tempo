# Tempo

**Windows용 타이머 · 알람 · 리마인더 · 스톱워치** — 설치 없이 실행 파일 하나로 동작합니다.

여러 단계로 이어지는 루틴 타이머, 화면에 떠 있는 카드, 모래시계·원형·디지털 같은 여러 디자인, 포모도로, Microsoft To Do 연동 리마인더를 지원합니다.

## 내려받기

[**Releases**](../../releases/latest) 에서 `Tempo-x.y.z-windows-x64.zip` 을 받아 압축을 풀고 `tempo.exe` 를 실행하세요.

- Windows 10 (1903 이상) · Windows 11, 64비트
- 처음 실행할 때 「Windows의 PC 보호」 창이 뜨면 **추가 정보 → 실행** 을 누르세요. (코드 서명 인증서가 없는 개인 프로그램이라 뜨는 안내입니다)
- 원하는 폴더(예: `C:\Tools\Tempo`)에 두고 실행한 뒤, **설정 → 바로가기 만들기** 로 시작 메뉴·바탕 화면에 추가하거나 **Windows 시작 시 자동 실행** 을 켜면 됩니다.

## 기능

### 타이머
- **단계 루틴**: 단계 여러 개를 차례로 진행 (예: 스트레칭 30초 → 휴식 10초 → …). 단계마다 다른 끝 소리
- **포모도로**: 집중 · 짧은 휴식 · 긴 휴식 · 간격만 정하면 자동 구성, 회차 표시
- 여러 타이머 동시 실행, 끝나면 반복, **끝나기 N초 전 예고음**, 단계마다 멈추고 기다리기
- **전역 단축키**: 타이머마다 시작·일시정지 / 처음으로 (다른 프로그램을 쓰는 중에도)
- **떠 있는 카드**: 항상 위에 뜨는 작은 카드 — 끌어서 이동, 가장자리를 끌어 크기 조절, 누르면 단계 목록, 오른쪽 클릭 메뉴
- **집중 화면**: 카드를 누르면 큰 화면 (포모도로는 집중/짧은 휴식/긴 휴식 탭, 오늘의 기록)

### 디자인 6종 × 색 테마 10종
클래식 · 원형 · **모래시계**(모래가 떨어지고 단계마다 뒤집힘) · 미니멀 · 디지털(7세그먼트) · 채우기
— 다크 · 미드나잇 · 포레스트 · 선셋 · 오션 · 노르딕 · 모노 · 라이트 · 로즈 · 샌드. 타이머마다 다른 디자인도 가능

### 알람 · 리마인더 · 스톱워치
- **알람**: 시각 + 요일 반복(매일·평일·주말·한 번), 다시 알림
- **리마인더**: 할 일 + 시각 + 메모 + 반복(매일·평일·매주·매월). 울리면 완료 / 10분 뒤 / 1시간 뒤
  - **Microsoft To Do 연동**: 설정 → Microsoft To Do → 「Microsoft 계정 연결」 → 표시되는 코드를 로그인 페이지에 입력. 목록 하나와 양방향 동기화 (휴대폰 To Do 앱과 함께 보기)
- **스톱워치**: 구간 기록

### 소리
내장 합성음 15종 + 내 소리 파일(wav · mp3 · flac · ogg), 미리 듣기, 전체 볼륨

## 데이터 · 제거

- 설정과 데이터: `%APPDATA%\Tempo\` (`data.json`, 기록 `tempo.log`)
- Microsoft 로그인 정보는 Windows DPAPI 로 암호화되어 이 PC · 이 Windows 계정에서만 쓰입니다
- **제거**: 설정에서 「Windows 시작 시 자동 실행」을 끄고 → 트레이 아이콘 → 종료 → `tempo.exe` 와 `%APPDATA%\Tempo` 폴더를 지우면 끝

## 자동화 (로컬 API)

`http://127.0.0.1:47830` (이 PC 안에서만 접근)

| 주소 | 설명 |
|---|---|
| `/api/timers` | 모든 타이머 상태 |
| `/api/timer?name=라면 3분&do=start` | 이름(또는 `id=`)으로 조작 — `start` `toggle` `pause` `resume` `reset` `skip` |
| `/status` · `/start` … | 설정의 「연동 타이머」 하나를 짧은 주소로 |
| `/api/show` | 메인 창 열기 |

## 직접 빌드

Rust (stable, `x86_64-pc-windows-gnu` 또는 `-msvc`).

```
cargo build --release
```

- GNU 툴체인은 `dlltool` 이 PATH 에 있어야 합니다 (`build.sh` 참고).
- 실행 파일 아이콘 · 버전 정보는 `assets/tempo-res.o` 를 링크합니다. 바꿀 때만 `python tools/make_res.py <버전> <windres 경로>` 로 다시 만드세요.

egui · eframe · rodio · tiny_http · tray-icon · rfd · ureq 를 사용합니다.
